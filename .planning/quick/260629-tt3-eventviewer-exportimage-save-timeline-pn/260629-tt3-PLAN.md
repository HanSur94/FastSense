<objective>
Implement GitHub issue #321: add a public `exportImage(obj, filepath, format)` method to
`EventViewer` so a rendered event-timeline figure can be saved as PNG or JPEG, mirroring
the contract and cross-platform handling of `DashboardEngine.exportImage` but targeting
`EventViewer`'s public `hFigure` property.

file without manual `print`/`getframe` boilerplate. This adds the same one-line export
already available on dashboards.

- New public method `EventViewer.exportImage` (additive; no signature/serialization change).
- Tests in `tests/suite/TestEventViewerExtras.m` covering happy path (PNG + JPEG),
  format inference, unknown-format error, and the not-rendered error.
- Updated class-header method list documenting the new method.

- Build the METHOD ONLY. Do NOT add a toolbar pushbutton (explicit follow-on in the issue);
  do not touch `buildRefreshToolbar` / toolbar layout.
- PORT the platform branch verbatim from `DashboardEngine.exportImage`; do not reinvent it.
- Additive & backward-compatible only. No change to Event/EventStore/DashboardWidget/Tag
  contracts. EventViewer is not serialized — no toStruct/fromStruct concern.
