<objective>
Speed up the DashboardEngine live-refresh hot path. Today every live tick, per Tag-bound FastSenseWidget, does three full `Tag.getXY()` pulls, a full re-downsample + pyramid-cache reset, an O(nE^2) event-marker diff, and per-element datestr/AGROW loops — even when zero new samples arrived. This plan adds a data-unchanged fast path, eliminates the duplicate `Tag.getXY()` pull, replaces the O(nE^2) marker diff with O(nE), vectorizes the engine's event-marker dedup, and vectorizes `getEventMarkers`/`formatTimeAxis_`.

Purpose: Make idle live ticks near-free and reduce work on active ticks, without changing any observable behavior or public API (one additive optional arg only).
Output: Faster `FastSenseWidget.update()`/`refresh()`, faster `DashboardEngine.computeEventMarkers`, regression tests, and a representative live-tick benchmark.
</objective>
