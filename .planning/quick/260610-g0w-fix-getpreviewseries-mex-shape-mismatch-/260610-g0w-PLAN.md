# Quick Task 260610-g0w: Preview-series shape fix + event extraction vectorization

Round-2 of the live-tick perf pass, driven by MATLAB profiler evidence (20 idle ticks,
8 Tag-bound widgets x 50k pts + 200 events: 26.5 ms/tick).

## Task 1 — getPreviewSeries: tolerate mex bucket-count bump (BUG + PERF)

Profiler showed minmax_core_mex called 320/320 times (cache 0% hit). Root cause: the
260512-live-mode bucket-math change in minmax_core_mex.c bumps nb internally
(bucketSize = floor(n/nb); nb_eff = floor(n/bucketSize); nb = max(nb, nb_eff)), so the
output is 2*nb_eff(+1). FastSenseWidget.getPreviewSeries accepts ONLY exactly
2*nBucketsEff(+1) and silently returns [] otherwise. Verified live: n=50000, nb=600 ->
mex returns 1204 (nb_eff=602). Consequences since 2026-05-12: slider preview lines
silently MISSING for Tag-bound widgets above PreviewRawThreshold_ (raw path under 100
samples still worked — which is why test_dashboard_preview_envelope passes), preview
cache never stored, every tick recomputes the downsample at both call sites.

Fix: derive the pair count from the OUTPUT length (odd length = tail anchor present),
instead of asserting the requested count. Reshape with the derived count.

## Task 2 — getEventMarkers: vectorized field extraction (PERF)

Profiler: isprop called 8,280 times / 20 ticks (2 per event per tick — Event objects
take the object-array branch). Fix: attempt whole-array extraction first
([raw.StartTime], [raw.Severity]) guarded by try/catch + shape validation, falling back
to the existing per-element loop for irregular shapes. Hoist the isprop probes out of
the loop in the fallback (probe raw(1) once).
