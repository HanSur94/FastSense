    Add a static method `[engine, warnings] = cloneForMachine(sourceConfig, sourceMachineId, targetMachine, mapper)` to `DashboardSerializer`. Validate args (`isstruct(sourceConfig)`, `ischar(sourceMachineId)`, `isa(targetMachine,'Machine')`, `isa(mapper,'CanonicalMapper')`) → else `error('DashboardSerializer:cloneInvalidArgs', ...)`.     Implement `targetResolver` as a NESTED function (shares the parent's `warnings` — closures capture by value, nested functions share the workspace, so the warnings MUST accumulate via a nested function, not an anonymous closure):
    ```
    function tag = targetResolver(srcKey)
        tag = [];
        lid = mapper.logicalIdFor(sourceMachineId, srcKey);
        if isempty(lid)
            warnings(end+1) = struct('sourceKey', srcKey, 'logicalId', '', ...
                'reason', 'no canonical mapping for source key');
            return;
        end
        e = mapper.resolve(lid, targetMachine.Id);
        if isempty(e)
            warnings(end+1) = struct('sourceKey', srcKey, 'logicalId', lid, ...
                'reason', 'target machine has no mapping for this sensor');
            return;
        end
        try
            tag = targetMachine.get(e.localKey);
        catch
            tag = [];
            warnings(end+1) = struct('sourceKey', srcKey, 'logicalId', lid, ...
                'reason', 'target tag not in catalog');
        end
    end
    ```
    Add a small file-local helper `cloneTempCleanup_(f)` (delete the temp if it exists; never throw). Namespaced header comment documenting the [engine, warnings] contract + the three reasons + that it reuses the load resolver path. Do NOT change saveJSON / load / configToWidgets signatures.
