<objective>
Build the pure-logic foundation for cross-machine comparison: add the missing `CanonicalMapper.resolve` method (the resolve-once-at-open seam that CMP-05 requires be absent from the live tick), an Octave-safe `buildCompareResolution_` helper that assembles per-machine row states with the LOW-confidence gate (CMP-04, invariant #4) and unit-mismatch detection, and a `compareSeriesColor_` helper that assigns stable per-machine colors by fleet insertion index (CMP-02).
