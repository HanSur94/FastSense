# v4.0 Multi-User LAN Concurrency — Milestone Archive

**Status:** ✅ Shipped 2026-05-13 (on `main` via PR #152; developed on a parallel branch)
**Phases:** 1029–1033 (5 phases, 20 plans)
**Archived:** 2026-06-09

This milestone delivered LAN-shared, multi-Companion concurrency: cross-host
advisory file locks, atomic temp+rename writes, append-only NDJSON event logs,
single-source "exactly once" MonitorTag event emission with an ack/comment
workflow, and a 50-Companion acceptance gate against a real SMB share.

## Phases

- [x] **Phase 1029: Concurrency Foundation** — Identity + Paths + FileLock primitive + AtomicWriter (OFD locks, mtime heartbeat, atomic temp+rename) — 5/5 plans
- [x] **Phase 1030: TagWriteCoordinator + LiveTagPipeline cluster mode** — per-tag lock around raw→.mat write; timer hardening; jitter; mtime change-detect — 2/2 plans
- [x] **Phase 1031: EventLog (Append-Only NDJSON) + EventStore SQLite rollback-mode migration** — lock-serialised appends; reader resilience; SMB-atomicity stress test — 4/4 plans
- [x] **Phase 1032: Single-Source MonitorTag Event Emission + ack workflow** — exactly-once emission via per-tag lock; ack/comment/visual-state; deferred listener notify; SQLite retry wrapper — 5/5 plans
- [x] **Phase 1033: Companion Integration + Snapshot Consolidator + Operator Docs + 50-Companion Acceptance Test** — SharedRoot through Companion; leader-elected snapshot; ops setup README; full acceptance gate — 4/4 plans
